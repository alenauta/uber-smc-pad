SMC-PAD sequencer overlay

Print at 100 % / actual size on card, then check the ruler below. Cut along the dashed outlines and cut out the grey holes. The left strip goes over the knobs (pull the knob caps off if they don't pass through), the right strip next to the buttons. The pads stay uncovered: their printed timing labels already match the timing page, except pad 14 (FILL, use the sticker).

The sizes come from the drawing in the manual. Measure your unit before you cut. Firmware 918 and later.

Sequencer mode

  • Shift + Note Repeat enter / leave. The Note Repeat LED flashes on the beat. Shift + pad: the normal Shift menu (preset, curve, transpose, octave).
  • PAD BANK tap: Step ↔ Play view (LED on = Play).
  • Hold PAD BANK: track layer: pad = select, hold src + tap dst = copy notes & scale (+ Shift = also ch/note/vol), + Stop + pad = mute, + Shift + Stop + pad = clear.
  • KNOB BANK: Track ↔ Pattern knobs (LED on = Pattern).
  • < > step pages of 16 (LED lit = more pages). Shift + < / > undo / redo.

Play view

  • Pads play the track from its base note in its scale (chromatic = drum kit). Root pads brighter. Shift-menu octave / transpose move the pads (transpose = one scale step).
  • Rec + Play: live recording (K4 = quantize strength, adjustable after recording); hold time sets the step's length. Hits on a step that already plays add chord notes (up to 4).

Transport & sync

  • Play: start / continue. Stop: stop; press again = back to the top.
  • Sync on (timing pad 15): the DAW's Start / Stop / clock drive the pad. Otherwise the pad sends clock.
  • Sync offset (KNOB BANK K8, −120…+120 ms): − early / + late (master & slave).

Root & scale

  • KNOB BANK K3 / K4: track root / scale (follow = global). Shift + K3 / K4: global, also normal mode (follow = preset, root = pad 1's note).
  • Pads 1–12: C…B, or chrom., major, minor, dorian, phryg., lydian, mixol., locrian, harm.min, pent.maj, pent.min, blues; none lit = follow.

Reading the pads while turning a knob

  • Amounts (volume, velocity, probability, quantize, steps, tempo, swing): bar from pad 1, dim → full. Micro-timing & sync offset: centre-out (− pads 8…1 early, + pads 9…16 late).
  • Choices light one pad: rate (pads 1–8 = printed 1/4…1/32T), ratchet rate, trig condition, root, scale.
  • Counts: MIDI channel (1 pad = ch 1 … 16 = ch 16), gate.
  • Base note / step note: pads 1–12 = keyboard, top row = octave. Ratchet count: pads 1–4.
  • Trig conditions (K7): always, 1:2, 2:2, 1:3, 2:3, 3:3, 1:4…4:4, first, fill, not fill.
  • Ratchet rate (K6): auto (split the step), 1/8, 1/16, 1/16T, 1/32, 1/32T, 1/64.

Rate = the editing grid

  • K8 / timing pads 1–8: notes keep their timing. A coarser grid keeps the notes in between (pad dim white). Shift + K8: the same steps faster / slower.

Pattern slots (16, pad = slot)

  • Hold Shift + Rec + pad: save (no pad = current slot). Hold Shift + Play + pad: load (playing: on the next bar). Off empty, dim used, full current. Target pad blinks 3× green / red.
  • Stop saves changes. Another slot: changes kept first; empty slot = new pattern; current slot = revert.
