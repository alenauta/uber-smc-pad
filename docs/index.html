How to Flash with SincoOTA (iOS / Android)

Heads up — SincoOTA often takes 2 attempts: In my experience (just like with the official firmware update), the first attempt reboots the SMC-PAD into recovery/updater mode and stops waiting to reconnect, and a second attempt (after unselecting and scanning again) writes the firmware. If yours completes in a single pass, you're already done.
  1. Prep

    Remove SMC-PAD from Paired Bluetooth Devices First

    Unplug the USB cable, close Midi Suite / CubeSuite, and switch the SMC-PAD ON. Open your phone's OS Settings → Bluetooth and Remove / "Forget This Device" if SMC-PAD is paired (if the OS keeps a background BLE-MIDI connection open, SincoOTA cannot complete the handoff). Copy SMC-PAD_925.fwsc to your phone.

  2. Attempt 1

    Select Device → Select Firmware → Start Flash

    Open the SincoOTA app, scan and select SMC-PAD, choose SMC-PAD_925.fwsc, and tap Start / Upgrade. If it flashes straight to 100%, you're done! Often, however, the pad reboots into recovery / updater mode (pad RGBs turn off or freeze, BT LED goes off) and the first attempt stops or stalls — nothing has been overwritten yet; proceed to Attempt 2.

  3. Attempt 2 · If Stalled

    Unselect Device → Search & Select Again → Flash to 100%

    In SincoOTA, unselect / disconnect the device, then search / scan again and select the newly found device (do not skip unselecting and re-scanning!). Select SMC-PAD_925.fwsc again and tap Start / Upgrade a second time — it should flash smoothly to 100% and reboot into the custom firmware.

Return to Stock & Safe Mode

  • Revert to stock anytime: Custom builds keep the stock bootloader and report version 000, so SincoOTA always accepts the official SMC-PAD_005.fwsc back using the same procedure above.
  • Updating custom → custom: If Attempt 1 reports "OTA failed" while already running custom firmware, run Attempt 1 selecting SMC-PAD_005.fwsc (to enter recovery mode), then unselect, scan & re-select, and choose the new SMC-PAD_925.fwsc on Attempt 2.
  • Boot-loop Safe Mode: Switching power ON → OFF within 5 s → ON → OFF within 5 s → ON boots on the 3rd start with custom drivers bypassed while keeping Bluetooth SincoOTA active.
